# Plan: Hadith Tracking Mode for Mishkat Al-Masabih

## Goal
Extend the existing syllabus system so that when the subject is exactly `مِشْكَاةُ الْمَصَابِيحِ`, all UI labels switch from "Page" terminology to "Hadith" terminology. No logic changes — only label swaps.

## Approach
- Add a `tracking_type` column (`'page'` or `'hadith'`) to `syllabus_configs`
- Backend auto-sets it to `'hadith'` when the subject matches Mishkat
- Frontend reads `tracking_type` from the config object and swaps labels accordingly
- All analytics, progress storage, APIs, and math remain identical

    updateNum: isHadith ? 'Update Current Hadith Number' : 'Update Current Page Number',
