# Plan: Blinking green indicator on teacher's assigned periods

## Goal
When a teacher selects a class on the attendance form, the period buttons (P1–P7) that are assigned to them in the timetable should show the period number in light green with a gentle blinking animation. All other periods remain unchanged.

## Changes Required

### 1. Backend: Add `teacher_id` to `get_timetable` response
**File:** `attendance.py` (line ~4495)

The `get_timetable` action currently returns `weekday`, `period`, `subject`, `teacher` (name only). Add `tt.teacher_id` to the SELECT so the frontend can compare it with the logged-in user's ID.

```python
# Before:
SELECT tt.weekday, tt.period_label, tt.subject, t.name as teacher_name

# After:
SELECT tt.weekday, tt.period_label, tt.subject, t.name as teacher_name, tt.teacher_id
```

And add `teacherId` to the response dict:
```python
{"weekday": r[0], "period": r[1], "subject": r[2], "teacher": r[3], "teacherId": r[4]}
```

### 2. Frontend: Fetch timetable when class is selected, extract "my periods"
**File:** `frontend/src/app/page.js`

- Add state: `const [myAssignedPeriods, setMyAssignedPeriods] = useState([]);`
- When `selectedClass` changes (in the existing `useEffect` that fetches marked periods around line 891), also call `getTimetable(selectedClass)`.
- Filter the timetable result for the current weekday (using IST), and collect period labels where `teacherId === user.id`.
- Store these in `myAssignedPeriods` (e.g. `["P2", "P5"]`).

### 3. Frontend: Add blinking green CSS class for my periods
**File:** `frontend/src/app/page.js`

In the period button grid (line ~2062–2078), add a new state: `isMyPeriod` that checks if `p` is in `myAssignedPeriods`.

When `isMyPeriod` is true AND the period is not selected and not marked, apply:
- `text-emerald-500` for the number color
- A CSS animation class for gentle blinking

Add a `<style>` tag or inline keyframe for the blink animation:
```css
@keyframes softBlink {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.4; }
}
.animate-soft-blink {
  animation: softBlink 2s ease-in-out infinite;
}
```

### 4. Period button JSX update (line ~2067)
Add `isMyPeriod` to the className logic:
```jsx
: isMyPeriod
  ? 'bg-emerald-50/50 text-emerald-500 border border-emerald-200 animate-soft-blink'
  : 'bg-gray-50 text-gray-400 border border-gray-100 hover:bg-gray-100'
```

The number span (line ~2074) also needs the green + blink classes applied when `isMyPeriod`:
```jsx
<span className={`${isMarked ? '...' : isMyPeriod ? 'text-emerald-500 animate-soft-blink' : 'relative z-10'}`}>
  {p.replace('P', '')}
</span>
```
