# Plan: Timetable Edit Permission for Teachers

## Overview
Allow admin to designate specific teachers as "timetable editors" via a list in Settings > System. These teachers can then edit the timetable directly from the dashboard's Timetable tab using a pencil icon to enter edit mode.

---

| File | Changes |

| `attendance.py` | Add `get_timetable_editors` / `save_timetable_editors` actions |
| `frontend/src/lib/api.js` | Add `getTimetableEditors` / `saveTimetableEditors` API functions |

## Step 1: Backend — Store & Retrieve Timetable Editors

### `attendance.py`
Follow the exact same pattern as `authorized_substitute_coordinators`:

- Add `timetable_editors` key in `system_settings` table (alongside existing `authorized_substitute_coordinators` init at line ~265)
- Add two new action handlers (near line ~6674, after coordinator handlers):

```
action: "get_timetable_editors"
  → SELECT value FROM system_settings WHERE key='timetable_editors'
  → Return { success: true, editors: [list of teacher IDs as strings] }

action: "save_timetable_editors"
  → Receive { editors: [ids] }
  → INSERT OR REPLACE INTO system_settings (key, value) VALUES ('timetable_editors', comma_separated_ids)
  → Return { success: true }
```

### `server.js`
- **New endpoints:**
  - `GET /api/timetable/editors` — any authenticated user (teachers need to know if they have permission). Calls `get_timetable_editors`.
  - `POST /api/timetable/editors` — admin only. Calls `save_timetable_editors`.

- **Relax existing timetable edit routes** (lines 1622-1658): Change the `req.user.role !== 'admin'` check to also allow users in the timetable editors list:

```js
// Helper function (add near top with other helpers)
function isTimetableEditor(user, editors) {
    return user.role === 'admin' || editors.includes(String(user.id)) || editors.includes(String(user.username));
}

// In each of the 3 routes (/admin/timetable/:weekday, /admin/teacher-subjects/:teacherId, /admin/timetable/period):
// Fetch editors, then check:
const editorRes = await callPython({ action: "get_timetable_editors" });
const editors = editorRes.editors || [];
if (!isTimetableEditor(req.user, editors)) return res.status(403).send('Forbidden');
```
